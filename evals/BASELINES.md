## What each method is

- **Guessing:** a random answer. With 101 classes, that is right about 1% of the time, and 5% for top-5.
- **Always the most common class:** the class with the most training images. It can score below guessing, because the largest class in training need not be the largest in validation.
- **Colour histogram:** how much of each colour the image has, ignoring where. Logistic regression then learns which colours go with which food.
- **Colour, shape and texture:** the colour histogram, plus edge directions (HOG) and fine texture (LBP), on 128 by 128 pixel images. These are the kind of hand-made features image classification used before deep learning.
- **Chi-squared kernel:** the same features, mapped so that a linear model compares histograms the way a chi-squared kernel does, which suits histograms better than comparing raw numbers. It has one fixed setting and was not tuned on these images.
- **Random forests on mined image parts:** the best result without deep learning that the dataset's authors published. It is on the test set, so it compares with this repo's test score, not its validation score.

## Limits

- The classical methods here use one simple classifier with default settings. More tuning, or a stronger classifier such as a kernel SVM, could score higher. The published result shows what a stronger method reached.
- The published number is from a different implementation and was measured on the test set.
